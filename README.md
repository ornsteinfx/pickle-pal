# Pickle Pal

A single-file retro pickleball trainer. Run it anywhere by opening index.html.

- Mastery course, quizzes, shop, customization, real-time doubles rally
- 7 randomized seasons that retheme every UI, music, ball, and outfit
- Winter: fading footsteps + snowball. Summer, fall, sakura, spring, retro, galaxy
- Play live at https://ornsteinfx.github.io/pickle-pal/
